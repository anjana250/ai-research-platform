# AI Research & Analysis Platform

## 🚀 Overview
The **AI Research & Analysis Platform** is a flagship, full-stack AI system that integrates multiple AI modules into a single platform.  
It demonstrates expertise in **LLMs, agentic AI, generative AI, anomaly detection, and cloud deployment**.

Modules include:
1. **RAG Q&A Service** – Document-based question answering using **AWS Bedrock** and LangChain.
2. **Agentic AI Orchestrator** – Multi-step AI workflows using **OpenAI/Hugging Face** models.
3. **Diffusion Image Generator** – Text-to-image generation using **Hugging Face diffusers** and GPU acceleration.
4. **Anomaly Detection Stream** – Autoencoder + XGBoost anomaly detection with streaming/batch data.

The platform is **fully containerized** and can be deployed on **AWS EKS**, with **CI/CD pipelines, monitoring, and logging**.

---

## 🛠️ Technologies
- **Backend:** Python, FastAPI, LangChain
- **LLMs:** AWS Bedrock, OpenAI, Hugging Face
- **ML/DL Models:** Autoencoder, XGBoost, Diffusers
- **Frontend:** Streamlit / React
- **Database & Storage:** PostgreSQL + PGVector, S3
- **DevOps:** Docker, Kubernetes (EKS), Helm, GitHub Actions
- **Monitoring:** Prometheus, Grafana, CloudWatch
